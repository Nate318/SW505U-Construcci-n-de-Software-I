# Pregunta 5 - Facade en sistema real

Este ejercicio usa el patrón Facade para ocultar la complejidad de varios sistemas:

- validación de DNI
- consulta de historial
- generación de número de cuenta
- firma digital
- notificación al cliente

La fachada `FachadaAperturaCuenta` permite abrir una cuenta con una sola operación.
